# 4方式で共通の待ち方と累乗を使う

hibana のコードと標準入出力で完結するプログラムは、4つの実行方式で同じ規則に従うことを目標とする。`Task.wait()` は4方式で廃止し、非同期処理を待つ場合は `.await`、開始済みのタスクの成功後に処理を呼ぶ場合は `then` を使う。`**` の指数は整数値に揃え、小数部分のある指数は実行時エラーとする。

同期で待つ `Task.wait()` を JavaScript 出力に加えるには、Promise（処理の完了を表す JavaScript の値）による待ち方の見直しが必要になる。整数値の指数は4方式で乗算の順序が揃っており、小数部分のある指数まで揃えるには計算方法と丸めの規則を定める必要がある。既存プログラムでは `Task.wait()` の用途に応じて `.await` または `then` を使い、`** 0.5` で求めていた平方根には `std::math::sqrt` を使う。[開発ロードマップ](../roadmap.md)
