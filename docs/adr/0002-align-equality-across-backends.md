# タスクと参照は同一性で比較する

`Task`（開始済みの非同期処理）と `Ref`（書き換えられる参照）に対する組み込みの `==` と `!=` は、同じタスクや書き換え先を指すかで判定する。参照先の内容による比較では、別の場所に書き込む2つの参照が等しくなり、後から書き込むと比較結果が変わるため、同一性を採る。別々に開始したタスクは戻り値が等しくても別の処理として扱う。[用語集](../../GLOSSARY.md)

関数型と `Async<T>`（開始前の非同期処理）の比較は、組み込みの比較が配列や構造体などの中身に進む場合も型検査で拒否する。関数名を評価するたびに同じ値を返すかどうかは方式によって異なる。型検査で拒否すれば、その違いが比較結果に現れることを防げる。関数を持つ構造体に `Eq`（型ごとに等しさを定めるトレイト）を実装すれば、その実装が選ぶ項目で構造体を比較できる。[開発ロードマップ](../roadmap.md)
